## 0. 这份文件是什么，不是什么

**是**：把一件已经发生的事——「公平性按预注册判据整体 FAIL，所有者接受该结果并决定本版不重采」——
写成可引用的文字，**并把后果逐条写死**，免得下次靠聊天记录推断、或被人当成「其实过了」。

**不是**：

- **不是改判**。判据 `aggregation = "all_rounds_must_pass"`，两轮不过，判定就是 FAIL，一个字不改。
- **不是把 FAIL 变成 PASS**。例外改变的是「这个 FAIL 怎么被接受、影响哪些表述」，不是结果本身。
- **不是新判据**，也不是「等下一版再说」的延期条。下一版重测的义务写在第 3 节 C4，到期不做即例外失效。
- **不是 G2 达标声明**。`g2_claim` 仍是 `false`；是否声明达标是另一个动作，且只能由所有者做。

## 1. 事实（可逐条复核）

判据（采集样本**之前**登记，sha256 未变）：预热 3 s、采样 10 s、每 arm 10 轮、
两条流份额各在 `[0.45, 0.55]`、Jain ≥ `0.95`、**每轮都要达标**。

| 线路 | arm | 结果 | 说明 |
|---|---|---|---|
| L1（16 Mbit/s，20 ms） | 四种 | 10/10 | 宽通道无问题 |
| L2（8 Mbit/s，50 ms） | `cc_off` | 10/10 | 量具无偏（20 轮落 0.499–0.502） |
| L2 | `cc_on_per_session_cap` | 10/10 | 中继令牌桶不是失败原因 |
| L2 | `cc_on` | **9/10** | 第 7 轮 0.430 / 0.570 |
| L2 | `cc_paced` | **9/10** | 第 8 轮 0.433 / 0.567 |

合计 **78/80**，整体判定 **FAIL**（因为要求「每 arm 全轮达标」，不是平均）。

归因：`r(丢包差, 份额偏移) = −0.706`；失败轮恰是丢包不对称最大的轮；中继
`shaping/dropped/limited` 全为 0；`cc_off` 全部落 0.499–0.502 ⇒ **不是限流、不是量具偏心**，
是 AIMD 在丢包不对称下的固有结果。

## 2. 例外的准确含义（三层，别混）

| 层 | 内容 | 本次取值 |
|---|---|---|
| **L0 判定** | 判据跑出来的结果 | **FAIL**，不可改写、不可「带例外地 PASS」 |
| **L1 记账** | G2 出口清单里这一项怎么记 | 记作「**带例外 EX-1 关闭**」，并强制附第 3 节后果 |
| **L2 表述** | 对外/对文档能怎么说 | 见第 3 节 C5 的正负清单 |

关键区分：**L1 关闭的是「本版是否还要为这件事挡着」，不是「公平性这一 NFR 已达标」**。
把这两件事写成一句「公平性已通过」，是本单据明确禁止的。

## 3. 后果（写明；每条都带失效条件与责任人）

### C1 判定状态：仍是 FAIL，引用时必须带数字

任何后续文书引用这一项，必须同时给出 **78/80** 与两轮具体数值（`0.430/0.570`、`0.433/0.567`）。
只写「公平性有小偏差，已接受」不合格——那会把可复核的事实降级成印象。
**责任人**：引用者；**检查方式**：搜「公平性」段落里是否出现 `78/80`。

### C2 结论强度上限：本例外只覆盖「本版不修 β、不改阈值、不重采」这一个决定

它**不**覆盖「公平性 NFR 达标」，**不**覆盖「慢链路 + 开拥塞控制时不出现分账偏移」这个性质。
换句话说：本例外让 G2 出口的记录可以往前走，但不给任何「已验证公平」的结论授权。

### C3 失效条件（出现任一，本例外自动作废，必须重测，不许引用旧结论）

1. **端侧机制改了**：AIMD 的 β（`src/.../main.rs` 现为 0.5）、RTO 策略、pacing 逻辑任一改动；
2. **链路形状或物理环境变了**：换机、换 kernel、`tc` qdisc/class 变更、netem 参数变更、
   或从单机 netns 换成跨物理主机；
3. **所有者重新预注册判据**（新时间戳 + 新 sha256）。

「时间过去了」不是失效条件，也不是续期理由；反之，「什么都不改就一直有效」也不成立——
只要有人动了上述任一项而没重测，这条例外就作废，G2 出口记录必须回退到「未决」。

### C4 下一版义务（到期不做 = 例外失效）

1. **先**登记新判据（新时间戳 + 新 sha256），**再**采样本；顺序反了即为「看到结果改规则」；
2. 证据必须含 `[evidence].required_fields` 的 provenance 三项：
   `git_commit` / `kernel_release` / `tc_qdisc_and_class`——本轮归档缺这三项，是真实欠账；
3. 逐轮原始目录须入库（本轮 80 轮原始目录已不在，只能靠 summary，属不可复现）；
4. **不得**用「重跑同一判据 + 这次全过了」替代新判据；同一判据重跑只能叫复现，不能叫 PASS；
5. **不得**调 β 或改阈值去解释已有数据。

### C5 措辞：可以说 / 不可以说

| 可以 | 不可以 |
|---|---|
| 公平性按预注册判据整体 **FAIL**（78/80） | 公平性**达标** / 通过 / 基本通过 |
| 所有者已**书面接受**该结果，本版不重采（EX-1） | 带例外地 **PASS** / closed_with_exceptions（那是 S6 的词，不是这里的） |
| 偏差源于 AIMD 丢包不对称，`r = −0.706`，非限流 | 「已定位并修复」 / 「机制问题已解决」 |
| 下一版以新判据重测 | 「下一版自然会好」 / 「时间够了就算过」 |
| 单机 netns 两条竞争流的观测 | 跨公网 / 跨物理主机的公平性结论 |

### C6 残留风险（已登记 `RISK.md` R-16）

慢链路（8 Mbit/s 级、50 ms、有抖动）下开启端侧拥塞控制时，约**每 10 轮出现 1 轮**分账偏到
43/57 量级；影响面限于单机 netns 观测，未在公网验证。等级的判定阈值为「出现用户可感知的
长期偏斜，或该现象在跨主机复现」——到那时本例外必须重开，不能拿 EX-1 继续挡。

## 4. 与 G2 出口的关系（只记账，不宣布达标）

G2 出口清单里，「公平性」一项由本单据以 **EX-1 带例外关闭**；
「NAT 可达性」一项由 S6 以 **条件计入**关闭（DOC-32 / ADR-016 §R3，带四条结构化例外）。
两项都不是「全绿」，读者在出口记录里一定能看到 `78/80`、`3/30`、类别 `3/4` 这些数字。

**本单据不声明 G2 达标**：`g2_claim` 仍为 `false`，`evidence_valid_for_pass` 仍为 `false`，
`auto_pass` 仍为 `false`。声明达标是所有者的一句话，工具与文档一律不自置。

顺带把 `g2_note`（2026-11-17）里列的四项实现欠账复核了一遍，状态写进
`g2-spike-verdicts.toml` → `g2_note_20261125`：cr-dht 已实现（2043 行，daemon 已接 `cr_dht::announce`）、
LRU 已接 `sched::wake_seed`、中继仍欠运维项（限流/观测/告警，未单列验收）、
打洞仅 3/30 且 BT 公网那条属 `direct-via-static-dnat`。**这次复核不为任何一项签发「已验证达标」**——
它只是把「旧注记」换成「当前状态」，避免有人拿 2026-11-17 的清单当挡路理由，也避免有人当证据。
